Step 1 · Gemini API key

Create your key in a few minutes.

You do not need to write code. The key identifies your Google AI Studio project, applies its rate limits, and lets Resume Toner send only the requests you initiate.

1

Open Google AI Studio

Sign in, accept Google’s terms, then open the API Keys dashboard. New users normally receive a default project and key automatically.

2

Create and copy a key

Select Create API key if no key exists. New keys are authorization keys restricted to the Gemini API by default.

3

Verify it in Resume Toner

Open the extension’s Settings, paste the key, and select Verify and save. The key stays in local Chrome storage and is excluded from backups.

What you’ll see in AI Studio

  1. Open the Google AI Studio API Keys page.
  2. Choose an existing project or let AI Studio create the default project.
  3. Select Create API key, then copy it once. Treat it like a password.
  4. Use AI Studio’s restriction control if an older key is labelled unrestricted.

Resume Toner

Privacy Policy

Last updated: August 30, 2026

Resume Toner is a local-first, open-source Chrome extension. It has no developer-operated backend, user accounts, analytics, advertising, or telemetry. The developer cannot view users' resumes or API keys.

Information handled

Resume Toner handles information that the user chooses to provide:

  • resume content, including identity, contact, location, education, work history, projects, and skills;
  • PDF files selected for resume import;
  • career evidence and optional user-confirmed chatbot context;
  • the URL and visible content of a job page captured after the user clicks the extension; and
  • a user-provided Google Gemini API key.

Local storage

Resume profiles, uploaded source PDFs, career evidence, job captures, tailoring runs, review decisions, settings, and application history are stored locally in Chrome-managed storage on the user's device. The Gemini API key is stored locally, is not synchronized, is excluded from backups, and is not sent to the Resume Toner developer. Chrome extension storage is not encrypted, so someone with access to an unlocked Chrome profile may be able to recover locally stored information.

Transfers to Google Gemini

Resume Toner connects only to Google's Gemini API and only in response to a user action. The extension uses the user's own Gemini API key.

  • PDF import sends text extracted locally from the selected PDF to Gemini so it can be structured for review.
  • Analyze sends the full resume, saved career evidence, optional user-confirmed context, and selected job listing to Gemini.
  • Compact sends relevant resume content and job requirements to Gemini.

Google's current Gemini API terms and pricing and data-use table distinguish between free and paid services. Google may use prompts and responses submitted through unpaid services to improve its products, including machine-learning technologies. Google states that prompts and responses submitted through paid services are not used to improve its products. Resumes can contain sensitive personal information, so users should review Google's current terms and choose an appropriate account and billing arrangement before sending data. Resume Toner does not use remote code; all executable extension code is included in its package.

How information is used

Information is used only to import, review, tailor, preview, export, and locally organize resumes. Resume Toner does not sell user data, use it for advertising, determine creditworthiness, or transfer it for purposes unrelated to its resume-tailoring function. No developer or other human is permitted to read user data through Resume Toner.

Retention and deletion

Information remains on the user's device until the user deletes it or uninstalls the extension. Users can delete application records, delete all local structured data, forget the API key, and export a backup that excludes the API key. Files downloaded by the user remain wherever the user saved them.

User responsibility

Resume Toner checks whether suggestions are supported by information the user supplied; it cannot independently verify that resume claims or chatbot memories are true. Users must review and confirm every exported claim.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions

General questions and issues can be submitted through the public source repository. Do not post resumes, API keys, or other private information in a public issue. Privacy and security reports may be sent privately to parthdhroovji1@gmail.com.
