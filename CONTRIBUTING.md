# Contributing

Contributions must preserve Resume Toner's local-first design, evidence guardrails, minimal Chrome permissions, and zero-telemetry default.

1. Create a focused branch.
2. Do not commit real resumes, job applications, API keys, `.env` files, logs, generated PDFs, or identifying fixtures.
3. Add or update tests for behavior changes.
4. Run `npm test`, `npm run build`, and `npm run audit:release`.
5. Explain user-data and permission effects in the pull request.

Public issues must use fictional or thoroughly sanitized examples.
