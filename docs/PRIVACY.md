# Privacy Policy

Last updated: August 25, 2026

Resume Toner has no developer-operated application backend, user account, analytics, advertising, or telemetry. Resume profiles, career evidence, captured listings, tailoring runs, decisions, and application history are stored in Chrome-managed storage on the user's device until the user deletes them or uninstalls the extension.

The Gemini API key is stored in trusted local extension storage. It is not synchronized, included in backups, logged, or sent to Resume Toner. Anyone with access to an unlocked Chrome profile may potentially recover locally stored information.

When the user invokes Analyze, the extension sends the entire resume, career evidence, and full job listing directly to Google Gemini using the user's API key. When the user invokes Compact, relevant resume content and job requirements are sent directly to Gemini. Google handles that information under the terms and privacy practices applicable to the user's Gemini API account.

Resume Toner does not sell data, use it for advertising, allow the developer to read it, or transfer it to other parties. Users can export a credential-free JSON backup, delete individual application records, delete all structured local data, and forget the saved API key.

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions or privacy requests may be sent to the support address on the Chrome Web Store listing.
